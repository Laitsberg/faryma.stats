# Статистика разносов — «композитор разносит»

Одностраничный дашборд по архиву разнесённых треков. Считает всё в браузере,
бэкенда нет.

## Запустить локально

Просто открыть `index.html` через локальный сервер (напрямую из файла не
заработает — браузер заблокирует чтение `data.csv`):

    python3 -m http.server 8000

Дальше http://localhost:8000

## Подключить живую Гугл-таблицу

1. В таблице: **Файл → Поделиться → Опубликовать в интернете**
2. Выбрать лист с разнесёнными треками, формат — **CSV**, нажать «Опубликовать»
3. Скопировать ссылку (вида `https://docs.google.com/spreadsheets/d/e/2PACX-.../pub?output=csv`)
4. В `index.html` найти строку

       const SHEET_CSV_URL = "";

   и вставить ссылку внутрь кавычек.

После этого `data.csv` больше не нужен. Google кэширует опубликованный CSV
примерно на 5 минут — правки в таблице появятся на сайте с этой задержкой.

## Какие колонки нужны

Скрипт читает по названиям заголовков, порядок не важен:

| Колонка  | Для чего                                              |
|----------|-------------------------------------------------------|
| `Что`    | «Артист — Трек {альт} [источник]» — разбирается regex'ом |
| `Оценка` | шкала; распознаётся 99,5% значений                     |
| `Кто`    | лидерборд заказчиков                                   |
| `Тип`    | донат / долг / заказ / очередь                         |
| `Откуда` | аниме / игра / фильм                                   |
| `Жанр`   | жанровая аналитика                                     |
| `Тэги`   | progressive / cover / meme / live                      |
| `Когда`  | тайм-код внутри стрима                                 |

Лишние колонки игнорируются, пустые строки пропускаются.

## Что считается

Шкала переводится в баллы 0–10: гениально 10, атлична 8, хорошечно 6,
нормас 4, ну такое 2, кринж-контент 0. Модификатор `+` даёт +0,3, `++` +0,6,
`-` −0,3, `- -` −0,6. Комментарии в скобках отбрасываются.

Страна определяется по письменности названия (кана, хангыль, иероглифы,
кириллица, латиница) — это приближение, а не настоящие данные о стране.

## Деплой на GitHub Pages

Положить `index.html` в репозиторий, включить Pages в настройках.
Если подключена живая таблица — `data.csv` коммитить не нужно.
