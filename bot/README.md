# Ответчик для чата стрима

Отвечает в чат Twitch на вопрос «а разносили ли этот трек?». Работает
через Moobot: в команде стоит «URL fetch», бот дёргает наш адрес и
печатает ответ. **Ключи Twitch не нужны** — ни Client ID, ни
двухфакторная защита. Достаточно прав на добавление команд.

```
зритель: !разнос unravel
Moobot:  TK from Ling Tosite Sigure — Unravel: атлична+,
         стрим №16 (04.08.2024), принёс Anonymous.
         Ещё 8 совпадений: https://farymastats.info/?q=unravel
```

## Откуда берутся данные

С самого сайта, по обычным ссылкам: `data.csv`, `js/parse.js`,
`js/config.js`, `js/aliases.js`. Своей копии архива здесь нет, и своей
копии правил разбора — тоже. Поэтому бот не может разойтись с сайтом:
если оценка «гениально+» на сайте считается шуткой, то и в чате она
шутка.

Архив перечитывается раз в десять минут. Обновился архив — обновился
и бот, передеплой не нужен.

## Как развернуть на Railway

1. **New Project → Deploy from GitHub repo**, выбрать `faryma.stats`.
2. Ничего настраивать не нужно: в корне лежит `Dockerfile`, и Railway
   собирает по нему. Ставить в образ нечего — бот обходится тем, что
   есть в Node, — поэтому сборка занимает секунды.
3. **Settings → Networking → Generate Domain**. Railway выдаст адрес
   вида `faryma-bot-production.up.railway.app`. Без этого шага сервис
   останется «Unexposed» и снаружи не ответит.
4. Проверить в браузере: `https://ваш-адрес/health`.
   Должно ответить `ок, разносов 6697, обновлено …`.
5. Переменные окружения не обязательны. При желании:
   - `BASE` — откуда брать данные, по умолчанию `https://farymastats.info`
   - `REFRESH_MIN` — как часто перечитывать архив, по умолчанию `10`

### Если сборка падает

Первая попытка у нас упала с «Failed to build an image» и советом
про статический сайт. Причина: Railway сам угадывает, что запускать,
а в корне репозитория лежит `index.html` — сборщик принял всё за
статическую страницу и не нашёл, что стартовать. `Dockerfile` эту
догадку отменяет: в нём прямо написано, что делать.

Если увидите ту же ошибку снова — проверьте в **Settings → Build**,
что выбран билдер **Dockerfile**, а не Railpack или Nixpacks.

Сервис ничего не пишет и не хранит: только читает публичные файлы
сайта и отвечает текстом. Секретов в нём нет.

## Как завести команды в Moobot

Панель канала → **Commands** → добавить команду.

**!разнос** — приносили ли трек:

- Command name: `разнос`
- Response: вставить `URL fetch - Full (plain) response`,
  в адрес подставить:

```
https://ваш-адрес/track?q=$(query URL encoded)
```

Вместо `$(query URL encoded)` нажмите кнопку
**Insert → Arguments - All command arguments (URL encoded)** —
Moobot подставит свой код сам. Кодированный вариант обязателен:
без него сломаются названия с пробелами и кириллицей.

**!я** — своя статистика:

```
https://ваш-адрес/user?q=$(username)
```

Здесь нужна кнопка **Insert → Username - User who sent the command**.

**!чтопринести** — вселенная, которой не хватает опенинга:

- Command name: `чтопринести`
- Response: `URL fetch - Full (plain) response` с адресом

```
https://ваш-адрес/almost
```

Аргументы не нужны. Каждый вызов называет новую вселенную из тех, что
почти собраны: «Tate no Yuusha no Nariagari: разнесли 3 из 5. Не
хватает: Falling Through Starlight (ED2)…».

**!статистика** — статистика по имени:

```
https://ваш-адрес/user?q=$(command arguments)
```

Кнопка **Insert → Command arguments**, а не «Mentioned @username».
Причина: на Twitch человек зовётся одним ником, а в таблице записан
другим, и упоминание тут не поможет. С аргументами он напишет
`!статистика своё-имя-из-таблицы` и найдётся.

Точного совпадения бот не требует: ищет и по куску имени, а если
подходящих несколько — покажет список, чтобы человек уточнил.

```
!статистика kuma
→ kumashisan: 72 трека, средний 6.68…

!статистика ivan
→ Точно такого не нашёл. Похожие: Ivan_Vitalyevich (55),
  ivanes (3). Уточни: !статистика имя
```

## Что отвечает

| адрес | что делает |
|---|---|
| `/track?q=…` | искали трек: оценка, стрим, дата, кто принёс |
| `/user?q=…` | заказчик: сколько треков, средний балл, лучшее, место в зачёте |
| `/almost` | вселенная, которой не хватает опенинга |
| `/chatters` | кто писал в чат за последний час — этим наполняется колесо |
| `/health` | жив ли сервис, сколько разносов, на месте ли каталог |

Ответ всегда короче 380 символов — чат Twitch режет длинные сообщения.

## Сбор чата для колеса

Сервис держит соединение с чатом стрима и запоминает, кто писал за
последний час. Этот список забирает [колесо](../wheel.html) — чтобы не
переносить участников розыгрыша руками.

Ключи Twitch и здесь не нужны: в чат можно войти анонимно, назвавшись
`justinfan` с любым числом. Такой гость умеет только читать.

Сообщения не сохраняются — только ник и время последней реплики.
Колесу нужен список имён, а переписка зрителей нас не касается. Боты
каналов (Moobot, Nightbot, StreamElements и прочие) в список не идут.

Настройки, все необязательные:

- `TWITCH_CHANNEL` — чей чат слушать, по умолчанию `farymacomposer`
- `CHAT_WINDOW_MIN` — за сколько минут считать человека «в чате»,
  по умолчанию `60`. Читается при каждом обращении, так что менять
  можно на ходу, без перезапуска.

Живо ли соединение, видно в `/health`: там сказано, слушаем ли чат и
сколько человек в нём набралось.

## Проверки

Бот покрыт тестами вместе с сайтом: `npm test` в корне репозитория.
Ошибиться в чате дороже, чем на странице: неверную строку увидят все
разом, и переписать её уже нельзя.
